# NCBI Portal & Search Engine Replica

An educational web application developed as a Computer Science group project to demonstrate biological information search and bioinformatics-related workflows.

## Features

- **Biological Information Search:** Search interface for exploring biological and biomedical records.
- **Submission Portal:** Demonstration interface for entering dataset and submission information.
- **Download Interface:** A page for exploring data-related download options.
- **Sequence Analysis:** Sample BLAST-style alignment results for educational demonstration.
- **AI-Powered Summaries:** Gemini AI integration for generating scientific summaries when correctly configured.

## Technologies Used

- React
- TypeScript
- Node.js
- Express.js
- Vite
- NCBI E-utilities API
- Gemini AI

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/amresh614/NCBI-Portal-Search-Engine-Replica.git
   ```

2. Open the project directory:

   ```bash
   cd NCBI-Portal-Search-Engine-Replica
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Project Status

This project is an educational prototype. Some features use demonstration data. The current sequence-analysis endpoint does not perform a live BLAST search, and the submission interface does not upload datasets to official NCBI submission systems.

External API features require the appropriate configuration and API credentials.
